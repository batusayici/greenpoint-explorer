# Franklin St block — Greenpoint Ave → Milton St (Premier's blockface)

Field photos of the mostly-brick spine block running from the Premier Organic corner
(Franklin × Greenpoint) north to Milton St, **same side of Franklin as Premier**.
This is the ground-truth set for **Step 3 (one-block Wizard-of-Oz)** of the inked-kit
validation pathway (`docs/superpowers/plans/2026-06-16-inked-kit-validation-pathway.md`):
each building's photo → hand-authored real params (sampled wall color → tint, storeys,
bays, stoop/awning) → auto-composed inked facade → compared back to the photo.

## What to shoot (per building, in order from Premier toward Milton)

Premier is building **01** (the corner anchor). Number each neighbor sequentially as you
walk toward Milton: 02, 03, 04 …

For each building, ideally:
- **`-facade`** — one shot as **flat-on / straight at the wall** as you can get (not
  angled). This is the likeness truth: I sample wall color and count bays + storeys from
  it, so square-on and evenly lit beats pretty. **Most important shot.**
- **`-wide`** *(optional)* — a shot showing this building plus its neighbors, so I can
  confirm the building order and relative widths.
- **`-zoom`** *(optional)* — close-up of one window / the cornice / the stoop if the
  detail is hard to read in the facade shot.

One whole-block shot showing the entire row in sequence is also gold — name it
`block-wide.jpg`.

## Naming

`<NN>-<short-name>-<shot>.jpg`  — keep it lowercase, hyphenated.

Examples:
```
01-premier-facade.jpg
01-premier-wide.jpg
02-facade.jpg
02-wide.jpg
03-redbrick-facade.jpg
block-wide.jpg
```

`<short-name>` is optional (business name, color, or just leave it off). `.jpg`, `.jpeg`,
and `.png` all fine. If you know an address or BIN for any building, jot it here under
"Building notes" — it makes the param authoring exact.
