## 8. Flyering law (✅ verbatim-sourced from the city code, current through LL 2026/126)

- **§10-119:** posting on any pole, tree, hydrant, bus shelter, mailbox, etc.
  is flatly illegal — no carve-out for event flyers. **§10-121:** $75–150 first
  offense, $150–250 repeat, **each flyer a separate violation**, tree postings
  doubled, and the name/number on the flyer is **presumed** the violator
  (DSNY can subpoena phone records).
- **Parks (56 RCNY §1-05(c)):** no posting in any park without a
  Commissioner's permit; each item a separate violation. Hand-held signs up to
  6 sq ft are fine.
- **Scaffolding/sidewalk sheds:** illegal to post (Construction Code §3301.9).
- **§16-118(5)** (the classic stoop/windshield handbill ban) is currently
  marked **[Repealed]** in the live code — most secondary sources still quote
  it as law. Hand-to-hand distribution to people is legal; littering rules
  still apply.
- **Newsracks (§19-128.1)** are the one affirmatively legal street surface:
  free-publication boxes with DOT registration, placement specs. ❌ No evidence
  any local outlet operates boxes in Greenpoint today.

**Practical rule for us:** physical = hand-to-hand at markets, permission-based
placements inside venues, The Greenline's print run, and being present at
events. Never poles, never parks, never sheds.
