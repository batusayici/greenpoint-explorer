# Seeding Roster — Wave 1 and beyond (2026-08-15)

Strategic target selection for the seeding waves (launch plan §3). Produced by
three independent passes so no single blind spot survives: (1) an empirical scan
of `cards.json` + the ingest ledger/roster (who is actually behind our cards),
(2) a docs-of-record sweep (interviews, Josh feedback, coverage scans, growth +
business-model docs incl. private-doc review — class-level findings only here),
and (3) an outside-in web-research pass mapping Greenpoint's community nodes
*without* reference to our data. Synthesis and scoring in the main thread.

**Selection criteria** (derived from the loops before any names were listed):

1. **Redistribution power** — an owned audience the org actually pushes to
   (newsletter, IG, member emails, physical board). The org sharing *is* the
   growth event.
2. **Wedge-network fit** — parents/camps is the declared first network
   (growth-engine §4); echo-chamber rule: saturate one network before opening
   the next.
3. **On-map truth** — "your events are live here" must be literally true at
   send time (`npm run preflight:send` re-derives counts the morning of send).
4. **Downstream strategic value** — Loop B supply potential (recurring
   submitter) or institutional/discovery-channel value.

Scores below are 0–2 per criterion, in that order (e.g. `2·2·2·1`).
