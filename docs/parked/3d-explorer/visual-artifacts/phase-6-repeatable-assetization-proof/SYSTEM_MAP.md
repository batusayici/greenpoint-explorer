# System Map

Status: Review-only v1 map of reusable visual families

## Purpose

This system map names the reusable families visible in the Phase 6 generated rasters. It is a review scaffold, not a public module contract, production taxonomy, or asset-pipeline interface.

## Facade Archetypes

1. Narrow service bay
   - Seen in `storefront-recombination-a.png`.
   - Tall, compact, one primary door/window rhythm, optional roll-gate or repair-bay language.

2. Two-bay retail pair
   - Seen in `storefront-recombination-b.png`.
   - Wider frontage, paired display rhythm, larger sign band, shared sidewalk base.

3. Compact corner / kiosk / symbolic edge
   - Seen in `storefront-recombination-c.png`.
   - Alternate geometry, corner face, small canopy or sign, symbolic cue without exact station geometry.

## Sign Bands

- Painted lintel band: dark green, red, or ochre field with hand-lettered fictional identity.
- Hanging blade sign: small perpendicular sign with glyph or short invented label.
- Awning-integrated sign: identity lives on the awning valance or adjacent narrow band.

## Awnings

- Striped cloth awning, warm off-white with muted green/red/orange stripes.
- Short canopy over a narrow bay.
- Compact edge canopy for kiosk/corner conditions.

## Doors / Entries

- Single service door with adjacent repair-bay or display panel.
- Paired retail entries with recessed rhythm.
- Corner entry or kiosk hatch with a smaller threshold.

## Windows / Storefront Displays

- Narrow gridded display window.
- Wide paired retail display.
- Darkened roll-gate or shuttered service opening.
- Small kiosk window or poster surface.

## Roll Gates

- Closed service gate with painted identity glyph.
- Partial gate behind a window/display rhythm.
- Decorative security grille used as texture, not as a separate factual claim.

## Sidewalk / Curb Modules

- Small concrete sidewalk slab base.
- Curb edge with warm shadow.
- Street strip or crosswalk edge for scale.
- Corner curb or symbolic transit-edge slab.

## Street Props

- Planter cluster.
- Bike / bike rack.
- Trash can.
- Mailbox or utility box.
- Sandwich board.
- Streetlamp / pole / bollard cluster.

## Poster / Decal Texture Modules

- Small rectangular posters.
- Torn sticker clusters.
- Painted wall glyphs.
- Window decals.
- Awning marks.
- Corner utility markings.

## Identity Glyphs

- Abstract diamonds, circles, arrows, sparks, leaves, suns, and tool-like marks.
- Glyphs must stay fictional-safe.
- Glyphs can repeat as a family, but each storefront needs local variation.

## Marker States

- Default map pin.
- Hover pin.
- Selected pin.
- Selected building outline.
- Card-anchor dot / tether endpoint.

## Place-Card UI States

- Compact selected card.
- Hover preview card.
- Dense comparison/list card.

All card content is review-only placeholder content. Do not reuse generated copy as factual product copy.

## Compact Map Controls

- Small mode chip.
- Zoom cluster.
- Icon buttons for map/filter layers.
- Controls should feel paper-integrated and compact, not like a large beige QA panel.

## Place-Index Patterns

- Right-side compact list with selected row.
- Small glyph marker beside each fictional place label.
- No distances, addresses, ratings, or factual metadata in review-only proofs.

## QA Overlay Patterns

QA overlays are separate from normal product-facing UI.

Allowed QA patterns:

- Tiny `review only` stamp.
- Small artifact title block on a proof sheet.
- Non-product notes in documentation.

Not product-facing:

- Debug hit-region overlays.
- Large beige QA harness panels.
- Acceptance-checklist cards inside the map UI.
- Developer labels, coordinates, or measured distances.
