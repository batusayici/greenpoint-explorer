# Greenpoint Isometric Explorer - MVP Scope

Status: Approved for Batch 1 documentation setup  
Date: 2026-05-26  
Creative direction owner: Batu  
Implementation owner: Codex

## Positioning

Greenpoint Isometric Explorer is a desktop/tablet-primary web prototype with basic mobile containment.

The MVP is not a map product yet. It is a polished, authored, interactive diorama that tests whether a tiny Greenpoint slice can feel visually distinctive, locally specific, and worth clicking.

## MVP Objective

Prove one thing:

> Can a small isometric Greenpoint map feel visually distinctive, locally specific, and worth clicking?

The MVP should make someone say:

> I want to explore more of this.

## Core Experience

The MVP is one authored scene, not a system.

Core loop:

1. Pan or zoom around a small Greenpoint-inspired isometric scene.
2. Notice a storefront, transit anchor, sign, or small detail.
3. Get pointer or tap feedback.
4. Click or tap to open a place card.
5. Learn one tiny factual thing.
6. Keep looking around.

## Included In MVP

- One compact isometric scene around Manhattan Ave / Greenpoint Ave.
- Desktop/tablet-primary layout.
- Basic mobile containment.
- Pixel-inspired HD visual style.
- Greenpoint DIY Sim art direction.
- 4-6 source-backed real named places, only if spatially coherent.
- Pointer/tap feedback.
- Desktop hover and click.
- Touch tap highlight and card open.
- Bounded pan and zoom.
- Static local data.
- Place cards with neutral factual copy.
- 2-4 ambient visual-only animation loops.
- Unofficial-map disclaimer.

## Geography

First scene:

> Manhattan Ave / Greenpoint Ave handheld diorama, using one compact intersection or adjacent storefront row.

Initial anchors:

- Peter Pan Donuts - 727 Manhattan Ave.
- Karczma - 136 Greenpoint Ave.
- Greenpoint Ave G station / subway entrance.
- 1-3 nearby storefronts only if spatially coherent.

Possible later expansion:

- Radio Bakery / India St, only if the rendered scene expands north toward India St.

## Geographic Rule

The diorama may simplify or compress distances for readability, but it must not relocate businesses onto incorrect streets or imply false adjacency.

The scene should feel like an authored miniature, not a precise GIS map.

## Business Representation Policy

Use public factual information only.

Every real place must include:

- Name.
- Category.
- Address.
- Source URL.
- Last verified date.
- Neutral description.
- Unofficial-map disclaimer.

Do not include:

- Ratings.
- Reviews.
- Endorsement claims.
- Fictional stories attached to real businesses.
- Claims of partnership or participation.

Default removal/editing policy:

> If a business objects to inclusion or factual presentation, remove or edit it on request.
