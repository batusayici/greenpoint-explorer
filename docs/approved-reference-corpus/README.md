# Approved Reference Corpus

Status: Protected canonical visual reference corpus  
Date: 2026-05-28  
Project: Greenpoint Isometric Explorer

## Purpose

This folder preserves the approved Batch 12+ raster/reference outputs that future Greenpoint Explorer visual work must cite.

These images are reference-only. They are not production assets, implementation-ready source files, final place data, final copy, final UI components, or a production asset pipeline.

This corpus exists so future UI, prototype, and assetization work can align to concrete visual evidence instead of memory, prose labels, or scattered historical folders.

## Protection Rules

- References listed here must not be overwritten, silently replaced, moved, or treated as disposable historical artifacts.
- Future outputs that use the Inked Indie / Compact Corner direction must cite this corpus.
- If future outputs conflict with this corpus, the conflict must be called out explicitly for Batu/ChatGPT review.
- Generated or historical micro-text in these images is not factual copy and must not be reused as production content.
- These references do not approve production art, a production asset pipeline, real Greenpoint business data, exact addresses, exact facades, exact station geometry, live data, backend systems, routing, deployment, or public interfaces.

## Path Integrity

Canonical approved-reference files may live under `docs/archive/visual-artifacts/`. Archive storage is preservation, not demotion.

Use the current paths in `MANIFEST.md` as the authoritative inspectable paths. If a required manifest path is missing, future visual gates must stop and report the broken reference before implementation.

## Corpus Contents

- `MANIFEST.md` lists canonical and supporting source images, plus known cautionary references.
- `USAGE_RULES.md` defines how future prompts, UI work, and assetization passes should use the corpus.
- `REFERENCE_INDEX.md` groups references by practical use: scene/world style, storefront modules, recombination, UI/card/marker behavior, density/readability, and cautionary styling.
