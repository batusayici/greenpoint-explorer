## Status

This is a docs-only visual-preproduction package. It does not approve final visual language, production placement, production visual assets, app architecture, public interfaces, React/Vite/Pixi setup, `package.json`, `src/`, build tooling, CI, deployment, or real-place cards.

This revision replaces the first Batch 9 pass because the earlier variants were too mechanically similar. The revised passing standard is that Batu should be able to choose or reject a visual direction from the artifacts themselves, not from explanatory prose.

## Files

- `variant-quiet.svg`
- `variant-balanced.svg`

- `REVIEW_GUIDE.md`

These are the only three Batch 9 variants. They use the same underlying hybrid slice constraints so Batu can compare emotional volume, marker/card hierarchy, signage density, street detail, storefront language, and composition without comparing three unrelated concepts.

## What This Batch Tests

- Whether the compact Manhattan Ave / Greenpoint Ave hybrid slice feels worth continuing.
- Whether Peter Pan plus the Greenpoint Av G station can carry identity when other storefronts are placeholders, fictionalized, unresolved, or omitted.
- Whether the scene has enough storefront massing, sidewalk context, signage, and street furniture to judge composition.
- Whether marker/card UI examples help discovery or create clutter.
- Whether the emotional volume should be quiet, balanced, or community-forward.
- Whether the hybrid real-plus-placeholder approach feels honest rather than evasive.

## Revised Visual Standard

The artifacts should be rejected if:

- Variants differ mainly by color.
- Storefronts read as mostly flat panels.
- Community-forward does not visibly stress-test density.
- Quiet is merely empty or desaturated rather than calm but place-specific.
- Balanced does not look like a plausible target direction.
- UI cards and markers do not visibly test hierarchy.
- Prose is required to understand the visual differences.

The revised SVGs add:

- Storefront doors, windows, awnings, sign bands, frames, depth, and cornice language.
- Street context including poles, bins, grates, planters, menu boards, curb/crosswalk details, and variant-appropriate stickers/posters.
- A stronger symbolic Peter Pan anchor.
- A Greenpoint Av G station anchor integrated into the corner sidewalk.
- Variant-specific marker/card hierarchy.
- A visible truth-status legend in each frame.

## Truth Status

Verified:
- Used only as source-context language in legends and notes.
- No production-accurate storefront geometry, exact station access geometry, or real-place cards are claimed.

Symbolic:
- Peter Pan is shown as a symbolic anchor only.
- Greenpoint Av G station is shown as a symbolic transit anchor only.
- Their drawn forms are source-aware orientation aids, not production-accurate facades, entrances, stairs, elevators, or frontage claims.

Placeholder:
- Generic storefront bays used to test storefront rhythm and massing.
- Placeholder names are not real businesses.

Fictionalized:
- Fictional shop signs are invented to test signage density and neighborhood texture.
- Fictionalized storefronts must not be read as verified businesses.

Unresolved:
- Opposite-side and background massing is intentionally labeled unresolved where the current source record does not clear production placement.
- No unresolved storefront is converted into a real business claim.

## How Batu Should Review

Open the three SVGs at the same scale and compare them side by side:

1. Start with whether the slice feels worth continuing at all.
2. Compare emotional volume: quiet, balanced, community-forward.
3. Check whether the Peter Pan plus G station anchors create enough identity.
4. Check whether the placeholder and fictional storefront strategy feels acceptable.
5. Judge whether markers and cards clarify discovery or crowd the world.
6. Note any trust breaks caused by storefront fictionality, unresolved labels, or card placement.

## Variant Roles

Quiet:
- Calm documentary storefront read.
- Sparse markers and one restrained card.
- Tests whether the hybrid slice can feel local and specific without overlay pressure.

Balanced:
- Likely target-direction test.
- Warmer storefronts, moderate signage, richer street context, and clearer clickable hierarchy.
- Tests whether the scene feels distinctive and usable without becoming noisy.

Community-forward:
- Upper-bound density test.
- More stickers, posters, accent blocks, multiple markers, and a louder card.
- Tests whether DIY/community energy adds life or starts to overpower the authored place.
