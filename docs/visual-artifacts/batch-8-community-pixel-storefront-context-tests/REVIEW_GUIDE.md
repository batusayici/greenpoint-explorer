# Batch 8 Review Guide

Label: **lo-fi / exploratory / not final**  
Date: 2026-05-26  
Test path: Community Pixel Storefront, not an approved final style

## Review Intent

Use these artifacts to decide what the next visual pass should test or refine. Do not treat any option as final production direction.

## Questions For Batu

### 1. Emotional Volume

- Does the Balanced hybrid feel warm enough, or does it need more OCCII/community energy?
- Does any element feel too social-sim-like, especially the green marker?
- Does the scene still feel like a Greenpoint storefront first?

### 2. Storefront And Map Clarity

- Can you read the storefront/sign/transit anchor before the UI draws attention?
- Does the compact Peter Pan + G station option feel locally specific enough?
- Does the Karczma option feel truthful, or does it create false adjacency / excessive compression?

### 3. Marker And Card Hierarchy

- Does the marker feel like a place/hotspot cue rather than a character marker?
- Does the label chip feel helpful without becoming a game HUD?
- Does the hybrid card feel factual and source-ready while still having community/flyer warmth?

### 4. Palette

- Which applied palette best supports Greenpoint reality and OCCII/community spark together?
- Which palette keeps UI accents visible without letting them dominate the storefront world?
- Is the palette too beige/brown/slate, too OCCII-literal, or too civic-restraint-heavy?

## Decisions This Package Can Support

- Continue Balanced hybrid, revise it warmer, or revise it quieter.
- Keep, revise, or replace the green attention marker.
- Continue the hybrid card direction or change card volume.
- Favor compact Peter Pan + G station for the first composition, or continue testing a Karczma-inclusive layout only if spatial truthfulness holds.
- Choose a palette application to refine in another lo-fi pass.

## Still Blocked After Review

- Final visual direction remains blocked until Batu explicitly approves one.
- Static style-frame production remains blocked until Batu approves visual direction and composition.
- React/Vite/Pixi implementation remains blocked until an approved static style frame exists.
