## What This Batch Tests

- Whether the Balanced hybrid has enough community warmth without weakening storefront/place readability.
- Whether the green marker reads as a place/hotspot cue, not a character marker.
- Whether the hybrid card feels factual and source-ready without becoming dry civic UI.
- Whether Karczma can belong in the first static frame without false adjacency or too-wide composition pressure.
- Which palette application gives Greenpoint reality while preserving the OCCII/community spark.

- It does not approve Community Pixel Storefront as final direction.
- It does not approve a static style-frame composition.
- It does not approve final palette, marker, card, typography, or production art.
