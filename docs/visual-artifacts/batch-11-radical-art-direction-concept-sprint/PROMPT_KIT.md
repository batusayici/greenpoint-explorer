# Visual-Generation Prompt Kit

Label: **prompt-ready / external generation or human design brief / not final art**  
Date: 2026-05-26

## Use Rules For Every Prompt

Every generated frame must be:

- Exterior only.
- Isometric or near-isometric.
- Greenpoint / Brooklyn storefront context.
- A navigable map-mode browsing scene.
- Inclusive of storefront facade, sidewalk or street corner, street furniture, signage, place marker / click affordance, and one place card or hover overlay.
- Visually distinct in medium and materiality from the other territories.

Every generated frame must avoid:

- Interiors.
- Cutaway rooms.
- Inside venues.
- Character dialogue scenes.
- Generic city scenes.
- Fantasy villages.
- Generic cyberpunk.
- Abstract poster-only compositions.
- Literal copying of reference images or real storefront photos.
