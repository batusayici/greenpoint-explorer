# Next-Step Recommendation

Label: **operational recommendation / not approval**  
Date: 2026-05-26

## Recommendation

Generate **two raster/image style frames per territory** before narrowing.

This is the strongest next operational step because the root failure was insufficient divergence. Narrowing to three territories too early risks repeating the same mistake: choosing based on prose, assumptions, or Codex taste rather than visual evidence.

## Suggested Batch 12 Scope

Create 12 raster/image frames total:

- 6 hero exterior style frames.
- 6 UI-integrated map browsing frames.

Optional, if time and budget allow:

- 6 place-card / hover-state treatments.

## Why Not Select 3 Territories First

Selecting three now would require Batu to judge from written territory definitions. That is not enough for art-direction selection, especially after a failed style-variant pass.

The six territories are intentionally far apart. The next useful filter is visual, not verbal.

## When To Bring In Human Visual Design

Bring in human visual design if:

- Image generation cannot maintain exterior map browsing while preserving radical medium difference.
- Generated outputs collapse into generic city imagery.
- UI markers and place cards feel pasted on rather than native to the world.
- Greenpoint / Brooklyn specificity remains label-dependent.
- Batu wants authored taste and composition control before choosing a production path.

## Prompt Execution Notes

Run each territory as its own mini-brief, not as a shared board.

For each generation:

- Use the territory prompt first.
- Generate at least four candidates.
- Keep only candidates that pass exterior map-mode requirements.
- Reject any image with interiors, poster-only framing, fantasy/cyberpunk drift, or missing UI logic.
- Compare the survivors at 20% zoom before reviewing full size.

## Output Package For The Next Batch

The next visual batch should include:

- Raster/image frames, not SVG diagrams.
- A thumbnail contact sheet that shows all territories at equal scale.
- A per-territory folder with hero and UI-integrated frames.
- A short review guide.
- A self-audit against `docs/VISUAL_ARTIFACT_STANDARDS.md`.

## Approval Reminder

Generating these frames would not approve any territory. It would only create visual evidence for Batu's decision.
