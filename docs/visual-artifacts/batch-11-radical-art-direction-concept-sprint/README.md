## Objective

Help Batu choose which one or two visual territories deserve deeper development for Greenpoint Isometric Explorer.

The six generated hero frames are intended to answer:

- Which directions are meaningfully different?
- Which directions fit exterior map-mode browsing?
- Which directions feel locally specific and worth clicking?
- Which directions have enough visual taste and production survivability to develop next?

The package still uses the thumbnail divergence rule:

> At 20% zoom, the options should look like different games.

## How To Review

1. Open `comparison-board.svg` first and compare the six frames at equal scale.
2. Use `FRAME_INDEX.md` to connect each image to its territory thesis and risk.
3. Use `REVIEW_GUIDE.md` to judge what matters now and what should wait.
4. Read `DECISION_MEMO.md` for Codex's recommended two survivors.
5. Use `NEXT_BATCH_BRIEF.md` only after Batu chooses which direction or directions advance.

## Exterior-Only Scope

Every concept territory and prompt is constrained to exterior map-mode browsing:

- Storefront facades.
- Sidewalk or street corner.
- Street furniture.
- Signage.
- Place markers or click affordances.
- One place card or info overlay.

Do not depict:

- Interiors.
- Cutaway rooms.
- Inside venues.
- Character dialogue scenes.
- Generic fantasy towns.
- Generic cyberpunk.
- Abstract poster-only compositions.
