## Status

This is a docs/artifacts-only concept-sprint package for radical visual divergence.

No app implementation, public interface, module boundary, package tooling, build configuration, final art direction, production visual language, or approved static style frame is introduced by this batch.

This batch is **not decision-grade yet** because it does not include actual raster/image style frames. It prepares the exact territories, prompts, review rubric, and operating standards needed for the next visual-generation or human-design pass.

## Files

- `POSTMORTEM.md` - critique of why the previous art-direction batch failed.
- `TERRITORIES.md` - six radically divergent concept territories with production notes, risks, prompts, and Batu review questions.
- `PROMPT_KIT.md` - prompt set for hero exterior frames, UI-integrated browsing frames, and place-card / hover-state treatments.
- `DIVERGENCE_MATRIX.md` - comparison matrix across visual and production criteria.
- `DECISION_RUBRIC.md` - definition of decision-grade visual evidence and review gates.
- `NEXT_STEPS.md` - operational recommendation for moving from prompts to visual evidence.
- `SELF_AUDIT.md` - batch self-audit against `docs/VISUAL_ARTIFACT_STANDARDS.md`.

## Objective

Help Batu choose between truly different visual worlds for Greenpoint Isometric Explorer, not small variants of a shared composition.

The next visual pass must satisfy the thumbnail divergence rule:

> At 20% zoom, the options should look like different games.

## Exterior-Only Scope

Every concept territory and prompt is constrained to exterior map-mode browsing:

- Storefront facades.
- Sidewalk or street corner.
- Street furniture.
- Signage.
- Place markers or click affordances.
- One place card or info overlay.

Do not depict:

- Interiors.
- Cutaway rooms.
- Inside venues.
- Character dialogue scenes.
- Generic fantasy towns.
- Generic cyberpunk.
- Abstract poster-only compositions.
