## What Each Variant Tests

### A. Community-heavy

Tests:
- More OCCII-inspired marker/type energy.
- Warmer, more social invitation.
- Whether chunky navy/white UI can coexist with an exterior storefront world.

Tradeoff:
- Highest emotional energy, highest risk of UI overpowering the world or implying social-sim systems.

### B. Balanced hybrid

Tests:
- Local storefront world as the dominant layer.
- Medium sticker UI.
- Civic clarity without losing warmth.

Tradeoff:
- Best balance candidate, but may need more personality if it feels too careful.

### C. Civic-heavy

Tests:
- Cleaner map-guide readability.
- Smaller flyer accents.
- Whether factual-place discipline can still feel charming and worth clicking.

Tradeoff:
- Best clarity, highest risk of becoming too polite or utility-like.

## What Batu Should React To

- Should the place card feel more factual, more community-flyer-like, or hybrid?
- Does the UI feel like it belongs to the map, or is it pasted on?
- Which palette has the right Greenpoint/OCCII balance?
