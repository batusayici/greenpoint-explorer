## What This Batch Tests

- Whether the compact Peter Pan + G station composition can support a more reliable creative-direction decision than Batch 8.
- Whether Community Pixel Storefront should stay quieter, stay balanced, or move more community-forward.
- Whether the marker, label chip, and card overlay feel plausible for a future interactive diorama without implying quests, NPCs, or a social sim.
- Whether actual Greenpoint references materially improve world specificity and scene credibility.
- Whether flattened source artwork with explicit colors fixes the Batch 8 palette-rendering issue.
