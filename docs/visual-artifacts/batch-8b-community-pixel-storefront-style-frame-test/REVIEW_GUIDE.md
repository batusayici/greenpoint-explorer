# Batch 8B Review Guide

Label: **lo-fi / exploratory / not final**  
Date: 2026-05-26  
Test path: Community Pixel Storefront, not an approved final style

## Review Intent

Use these artifacts to answer one question:

> Which emotional-volume direction, if any, makes the creative-direction decision visually answerable?

Do not treat any option as final production direction.

## Questions For Batu

### 1. Emotional Volume

- Which variant best balances Greenpoint specificity and community warmth?
- Does the quiet option become too polite?
- Does the community-forward option become too gamey or too flyer-dominant?
- Does the balanced option actually hold the tension, or does it still feel indecisive?

### 2. World Leadership

- Does the scene read as a Greenpoint storefront slice before the overlays explain anything?
- Does Peter Pan feel recognizable enough as the anchor without pretending to be an exact reproduction?
- Does the G station feel like a local orientation anchor rather than a transit map feature?

### 3. Marker And Card Plausibility

- Does the marker read as a hotspot/place cue rather than a character cue?
- Does the label chip help without becoming HUD chrome?
- Does the card feel like a plausible future interaction state instead of a poster pasted over the world?

## Decisions This Package Can Support

- Keep Community Pixel Storefront quieter, warmer, or more community-forward.
- Keep, revise, or replace the current marker/card family.
- Continue toward a later proposed static style-frame production pass, or request another visual test first.

## Still Blocked After Review

- Final visual direction remains blocked until Batu explicitly approves one.
- Static style-frame production remains blocked until Batu approves visual direction and composition.
- React/Vite/Pixi implementation remains blocked until an approved static style frame exists.
