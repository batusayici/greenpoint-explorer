# Development Brief

Label: **survivor development brief / not approval**
Date: 2026-05-26

## Batch Frame

Batu has approved a next test step for two survivor directions:

- Soft Pixel Neighborhood Sim.
- Inked Indie Graphic Novel.

This approval does not approve final visual direction. The batch tests whether either direction can become a usable visual system for the map-mode MVP.

## Shared MVP Constraints

- Web-first clickable isometric diorama.
- Map mode only: pan, zoom, hover, click, and place cards.
- Exterior/storefront-first.
- Manhattan Ave / Greenpoint Ave area as the first slice.
- No interiors.
- No avatars, NPC simulation, quests, or events system.
- No fantasy props or magical-realism drift.
- No generic startup illustration.
- No mobile-game toy town language.
- No overbuilt UI clutter.
- No unsupported real-place claims.

## Survivor 1: Soft Pixel Neighborhood Sim

### Thesis

A warm HD-pixel storefront browser where Greenpoint feels handmade, legible, locally textured, and immediately clickable.

### Preserve From The Hero Frame

- Clear near-isometric storefront rows and corner geometry.
- Strong entrance readability and sidewalk/street logic.
- Chunky but detailed brick, awning, sign, window, curb, bike, pole, planter, and community-board treatment.
- Warm approachable mood without turning into fantasy, quest UI, or a character sim.
- Marker affordance that feels native to the map world.

### Strengthen

- Stronger difference from generic retro pixel neighborhood art.
- More explicit UI state language: default, hover, selected, and card attachment.
- More Greenpoint/Brooklyn specificity through facades, roll gates, stickered poles, handmade flyers, sidewalk clutter, independent storefront signs, and community boards.
- Cleaner place-card hierarchy borrowed from Civic Atlas clarity.
- Controlled Xerox-style sticker/flyer pressure without collage takeover.

### Avoid

- Low-resolution nostalgia.
- Generic cozy-game storefronts.
- Full game HUD, quest markers, XP, inventories, or fantasy UI.
- Overcrowded pixel detail that hides click targets.
- Treating every surface as equally noisy.
- Copying real storefronts or making exact placement claims.

### UI / World Integration Hypothesis

Soft Pixel can make UI feel native by treating markers, hover states, and selected cards as crisp pixel-sticker affordances attached to storefront entrances. The UI should be brighter and cleaner than the world, but still physically grounded through pixel edges, tiny shadows, and a restrained sticker/card material.

### Production Viability Hypothesis

Soft Pixel can become repeatable if storefronts are built from modular facade parts, awnings, sign bands, sidewalk tiles, street props, and a controlled library of texture details. The risk is detail cost: every storefront cannot require bespoke pixel painting at hero-frame density.

### Specific Risks To Test

- Does the place card stay legible against detailed pixel texture?
- Does the hover state read without becoming a game HUD?
- Can the style remain locally specific when modularized?
- Does it still feel fresh compared with older Community Pixel-adjacent work?
- Are markers understandable at map scale?

## Survivor 2: Inked Indie Graphic Novel

### Thesis

A hand-authored exterior Greenpoint map panel where storefront quirks, linework, street texture, and restrained UI make the block feel specific and worth clicking.

### Preserve From The Hero Frame

- Authored ink linework and confident facade detail.
- Strong local storefront identity.
- Dense but readable street-corner composition.
- Expressive signage, awnings, posters, bikes, poles, planters, benches, mailboxes, and sidewalk grit.
- Adult, local, editorial taste rather than cute game language.

### Strengthen

- Clearer UI state system: default, hover, selected, and card attachment.
- More explicit map readability at zoomed-out scale.
- A restrained caption-panel place-card language that borrows Civic Atlas hierarchy without losing the inked world.
- Controlled Xerox surface pressure through flyers, stickers, and paper texture.
- Repeatable rules for line weight, hatching density, shadow shapes, and color restraint.

### Avoid

- Character-scene or story-panel drift.
- Speech bubbles, comic action effects, noir overload, or melodrama.
- Dense hatching that hides entrances or markers.
- Generic indie-city melancholy.
- Clean SaaS card overlays pasted on top of illustrated art.
- Copying real storefronts or making exact placement claims.

### UI / World Integration Hypothesis

Inked Indie can make UI feel native by using precise inked callout pins, drawn hover brackets, light wash highlights, and caption-panel cards. The card should feel designed, not messy: an illustrated object with clean hierarchy, not a generic comic box or a product dashboard card.

### Production Viability Hypothesis

Inked Indie can become repeatable only if the style system defines strict rules for line weights, facade simplification, shadow density, paper texture, and UI hierarchy. It likely needs stronger human art-direction oversight than Soft Pixel because its value comes from authored specificity.

### Specific Risks To Test

- Does the UI remain legible over linework and hatching?
- Can the style stay map-first rather than illustration-first?
- Can storefront detail be modularized without losing authorship?
- Does the selected state feel native but precise?
- Does production cost become too high for MVP scope?
