## Soft Pixel Neighborhood Sim

### Prompt SP-A: UI / World Integration Frame

Use case: stylized-concept
Asset type: Batch 13 UI/world integration frame
Primary request: Create an exterior-only near-isometric Greenpoint, Brooklyn map-mode browsing frame in the Soft Pixel Neighborhood Sim direction, based on the approved Soft Pixel hero-frame spirit but not copying it literally.
Scene/backdrop: A compact fictionalized Greenpoint storefront corner near Manhattan Ave / Greenpoint Ave, with brick and vinyl facades, awnings, roll gates, sidewalk slabs, curb, crosswalk edge, bike racks, stickered utility poles, planters, community board, street signs, window decals, and independent storefront personality.
Visual style: Warm HD pixel-inspired raster art with crisp stepped edges, chunky readable forms, subtle pixel texture, modern local color, controlled surface detail, and high thumbnail clarity. Borrow Civic Atlas clarity in information hierarchy and only a small amount of Xerox sticker/flyer texture on poles, boards, and windows.
UI/world requirements: Show three different clickable storefront states in the same scene: one default clickable place with a quiet pixel-sticker marker at the entrance, one hovered storefront with a restrained pixel outline or soft glow locked to the facade, and one selected storefront with a stronger entrance marker plus one small selected place card. The UI should feel like tactile pixel stickers and clean map affordances native to the world, not a full game HUD.
Composition: Use a browsable map camera, not a poster or character scene. Storefront entrances, markers, sidewalk paths, and the selected card must be readable at thumbnail scale.
Text treatment: Include only short placeholder sign-like text where needed, treated as non-final generated texture. Place-card text should be blocky and hierarchic, but not relied on for the review.
Avoid: Apply the shared negative constraints. Also avoid low-resolution nostalgia, fantasy RPG UI, quest icons, XP bars, inventory panels, generic cozy-game storefronts, and clutter that hides click targets.
