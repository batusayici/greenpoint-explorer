## Purpose

This packet tests whether the accepted Phase 2DTR-2 four-target fixture can assemble into a deterministic four-corner raster instruction attempt for the Manhattan Ave x Greenpoint Ave MVP scene.

It does not produce or approve a production scene, normal-mode replacement raster, production asset, production asset pipeline, public interface, exact facade/frontage/address/station geometry, or public factual readiness.

## Review Question

Can the Phase 2DTR-2 structured fixture drive a coherent four-corner regenerated raster/spec attempt, or should the fixture be revised before a true regenerated image pass?

- `generated/four-corner-regenerated-raster-attempt.json` - deterministic four-corner scene prompt, target instructions, generation rules, and non-approvals.
- `generated/visual-instruction-provenance.json` - maps visible instructions back to 2DTR-2 fixture/spec sources and status lanes.

## What This Proves

- The accepted four-target fixture can be assembled into a single deterministic four-corner raster instruction packet.
- All four storefront targets carry review labels, categories, corner assignments, sign cues, reference-image sets, manual-draft facade fields, and explicit blocked claims.
- The packet can compare against MVP-29E without app source edits, fixture implementation, package/tooling changes, production/public-readiness changes, or normal-mode behavior changes.

## What Remains Blocked

- Exact tenant frontage/order.
- Exact facade, sign, entrance, and window geometry.
- Exact address placement.
- Exact Greenpoint G station geometry or entrance placement.
- Production asset approval.
- Production asset pipeline approval.
- Public factual readiness.
- Normal-mode raster replacement.
- Product/public schema or public-interface approval.
- Live source acquisition, scraping, APIs, or source-vendor decisions.

## Review Choices

- Accept: Treat the deterministic four-corner raster/spec attempt as sufficient to move to Phase 2DTR-4 QA Acceptance / Gap Report, or explicitly open a true generated raster image pass if Batu wants one before gap closure.
- Revise: Tighten target fields, reference handling, prompt shape, or gap reporting before any true generated raster pass.
- Reject: Return to Phase 2DTR-2 fixture structure.
