## 🔴 Blocker first — the operator is blind, and the known fix is wrong

`./scripts/posthog-pull.sh` did not run. **The cause is not missing secrets:**

- `POSTHOG_READ_KEY` — **present** in the routine environment ✅
- `POSTHOG_PROJECT_ID` — **present** ✅
- `.env.local` — absent (expected in cloud; the script's `set -a; . ./.env.local`
  line was skipped and the env vars exported directly, per the routine prompt)
- **`us.posthog.com:443` is denied by the environment's egress policy** ❌

Evidence (verbatim, this run):

```
$ curl -sS -X POST "https://us.posthog.com/api/projects/$POSTHOG_PROJECT_ID/query/" ...
curl: (56) CONNECT tunnel failed, response 403

$ curl -sS "$HTTPS_PROXY/__agentproxy/status"
"recentRelayFailures": [
  { "ts": "2026-07-28T13:35:20.720Z", "kind": "connect_rejected",
    "detail": "gateway answered 403 to CONNECT (policy denial or upstream failure)",
    "host": "us.posthog.com:443" } ]
```

Per the proxy README a 403 on CONNECT is an organization egress-policy denial:
report it, never route around it. So the run stopped there.

**This matters beyond one readout.** `growth-weekly/SKILL.md` and the launch plan
both record the cloud-analytics fix as "add the two env vars as secrets in the
routine's environment." That is now demonstrably insufficient — the vars are
there and the pull still fails. **Every future Tuesday run lands `[data pending]`
until the host is allowlisted.** This PR corrects that line in the skill.

**Fix (Batu, ~2 min, claude.ai/code → the routine's environment → network
policy):** allow `us.posthog.com` for the growth-readout environment. If the
policy is all-or-nothing rather than per-host, the fallback stays: run
`./scripts/posthog-pull.sh` locally and paste the output into the open PR.

Same class of gap, third time (Vercel Analytics off Jul 15–21 → untagged invite
links → now a blocked egress host). The pattern is that **the measurement layer
fails silently and is only caught at readout time.** Proposal 1 below is the

  is not viable in cloud and the loop reverts to local `/growth-weekly`.

  blocks a good run, drop it — a noisy gate is worse than none.

  this PR is a readout. Say the word and it ships as its own gated change.
